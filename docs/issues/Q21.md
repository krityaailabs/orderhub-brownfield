# Q21: Order list status filter is case-sensitive

**Reported by:** support · **Severity:** low
**Labels:** agent-ok

`GET /orders?status=shipped` returns an empty list. `GET /orders?status=SHIPPED` works. Support's dashboard sends lower case. The filter should accept any case and surrounding spaces.

**Done when:** `status=shipped`, `status=SHIPPED` and `status=" Shipped "` return the same orders; a test covers it; nothing else changes.
