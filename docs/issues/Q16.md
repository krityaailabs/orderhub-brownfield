# Q16: A comma in a customer name stops the nightly billing batch

**Found by:** the billing module map (Section 8, Lecture 8.2) · **Severity:** high (no billing file at all), low likelihood so far

`write_billing_handoff` writes names with Python's `csv` module, which quotes a name containing a comma (`"Smith, John"`). The legacy `HandoffReader` splits every line on commas and reads columns by position, so the currency lands in the subtotal column and `Long.parseLong("USD")` throws. The batch exits 1 and writes no file; finance gets nothing at 04:00.

Pinned by `tools/tests/test_billing_contracts.py::test_comma_in_a_name_stops_the_batch_known_issue_q16`. Options for the fix (needs the billing team): reject commas at customer creation; replace commas when writing the handoff; or teach the reader to parse quoted CSV (a contract change on the Java side).
