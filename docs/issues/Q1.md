# Q1: Same customer can register twice with different capitals

**Reported by:** marketing operations · **Severity:** medium (duplicate accounts, split order history)

`aiko.tanaka@example.com` already exists. Registering `Aiko.Tanaka@Example.com` creates a second customer instead of being rejected.

Email addresses should be treated as case-insensitive when checking for an existing customer.

**Acceptance criteria**
1. Registering an existing email with different capitals returns 409.
2. Registering a genuinely new email still returns 201.
3. A test reproduces the bug before the fix and passes after it.
4. No change to existing customer records is required in this issue.
