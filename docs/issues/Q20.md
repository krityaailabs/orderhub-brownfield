# Q20: Loyalty points

**Requested by:** marketing, with finance copied · **Priority:** next quarter's launch

We want customers to earn loyalty points when they buy, so we can start a rewards programme in the spring. For launch:

- Customers earn **1 point for every full 1.00** they spend (so an order total of 12.99 earns 12 points).
- Points should only count for orders that actually go out; cancelled orders shouldn't earn anything.
- If a customer returns items, they shouldn't keep the points for what they returned.
- Support needs to see a customer's balance and history, to answer "where are my points?" questions.
- Spending points (redemption) comes later, after finance has looked at how it affects invoices and tax. **Not for launch.**

Finance (copied): "No change to the nightly billing file for launch, please. Points are not money until redemption exists."
