# Five dashboards that lie (Lecture 12.6)

Each tile below was shown to OrderHub's leadership at the end of the pilot. All five are built from the lab's synthetic data (tile 1 is an illustrative vendor figure). For each, decide before reading `ANSWERS.md`: **what does it actually measure, why is it misleading, and what would you show instead?** Write your verdict in one line each.

| # | Tile | Headline |
|---|---|---|
| D1 | "AI share of code" (tool vendor's dashboard) | **61% of our new code was written by AI this quarter** |
| D2 | "Throughput" | **Merged pull requests per week up 93%** (6.8 → 13.1) |
| D3 | "Pilot users vs the rest" | **Agent users merge 2.2× as many pull requests as non-users** (8.3 vs 3.8 per week, four people each) |
| D4 | "Quality held" | **Rework barely moved: 9% → 12%** (all pull requests merged in each period, fixes within 21 days) |
| D5 | "Reviews keep up" | **Time to first review unchanged: 4.5 h → 5 h** (median) |

Scoring: one point for naming what each tile measures, one for the flaw, one for a better replacement. 12 or more of 15 is good.
